# Rules of motion — interactive visualiser

Interactive implementation of the lattice-path "rules of motion" from
S. O. Warnaar, *The Andrews–Gordon identities and q-multinomial coefficients*
(arXiv:q-alg/9601012), §5.2 — the undressed (N = 1) case with i = i′ = k + 1.

The page enumerates all restricted lattice paths for k ≤ 4, generates each one
from its unique minimal configuration via the elementary moves of Definition 10
and Figures 5–6, and re-verifies Propositions 4 and 5 live in the browser on
every load. Any path can be animated move by move, forwards (construction) or
backwards (reduction).

Single self-contained HTML file, no dependencies: open `index.html` in any
browser, or visit the hosted page.

Built as part of a master's thesis project in mathematics at Stockholm
University.
