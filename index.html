The rules of motion — Definition 10, Figures 5–6, Proposition 4

Every path is built from the minimal path of some content n = (n₁,…,nₖ): particles in a single column each, largest charge leftmost, one empty column between neighbours. Particles then move one at a time, in a fixed order: all charge-1 particles first, then charge-2, …, then charge-k; within a charge, the rightmost first. A particle that stops never moves again.

The moving particle of charge t occupies a column pair: t−r units at column x, r units at x+1. One elementary move pours one unit from x to x+1 (weight +1). It is allowed iff the pair ahead stays within the particle’s own charge: r + 1 + f(x+2) ≤ t — the bound is t, not k.

When the pour reaches r = t − f(x+2) exactly, the particle re-bases: the f(x+2) units ahead are absorbed into the mover and the same number are emitted from its tail at x — the passed particle re-appears behind. With f(x+2) = 0 this is ordinary free motion. That single rule reproduces all of Figures 5 and 6: the blocked configurations are exactly those where no pour is allowed.

Uniqueness of the reduction (Proposition 4) is not assumed anywhere — it is checked live, path by path, in the badge on the left and the panel below.
